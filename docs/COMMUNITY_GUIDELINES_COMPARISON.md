## 2. 니터즈만의 차이점

### ① 저작권을 "최상위 금지 행위"로 둠
- 토스증권의 1순위 위험이 **허위 정보 · 투자 권유**, 당근이 **사기 · 사생활 침해**라면, 뜨개 커뮤니티의 1순위 위험은 **유료 도안 무단 공유**예요.
- 해외 뜨개 커뮤니티(Ravelry 등)와 국내 카페에서도 "도안 공유해 주세요" 요청이 반복적인 분쟁 원인이라, 공유 **요청 행위 자체**도 금지 대상으로 명시했어요.
- 권리자(디자이너) 전용 신고 경로를 따로 둔 것도 두 서비스에는 없는 부분이에요.
- 반대로 **무료 도안 링크, 출처 표기한 작품 사진, 도안 해석 질문**은 허용 범위로 명확히 적어 과잉 제재를 막았어요.

### ② 상업 활동을 "전면 금지"가 아닌 "투명성" 기준으로 구분
- 당근은 동네생활에서 홍보 · 구인구직을 제한하고, 토스증권은 투자 권유를 금지해요.
- 니터즈는 디자이너 · 개인 판매자가 커뮤니티의 핵심 구성원이라, **프로필 판매 안내 · 테스터 모집은 허용**하고 **뒷광고 · 도배 · 선입금 요구**만 막아요.
- [광고] · [협찬] · [제품 제공] 표기 의무를 둔 것이 차별점이에요.

### ③ "테스터 모집" 카테고리 전용 규칙
- 도안 테스터 모집은 뜨개 문화 고유의 활동으로, 두 서비스에 대응하는 항목이 없어요.
- 조건 · 기간 · 보상 명시를 요구하고, 참가비 · 실값 선입금 요구는 **즉시 영구 제한**으로 사기를 차단했어요.

### ④ 실력 비하 금지 — 취미 커뮤니티 특화
- 일반적인 욕설 · 모욕 금지 외에 "이걸 작품이라고", "초보는 올리지 마세요" 같은 **실력 비하**를 명시적 금지 행위로 넣었어요.
- 조언은 **작성자가 요청했을 때** 하도록 권장해, 입문자가 첫 작품을 올리기 부담스러운 문제를 줄였어요 (타겟: 2030 입문 · 취미 니터).

### ⑤ 제재가 "등급 × 누적"의 2차원 구조
- 토스증권은 위반 내용과 관계없이 **삭제 횟수**만으로 제한 기간이 늘어나요. 가벼운 도배와 심각한 위반이 같은 1회로 계산되는 구조예요.
- 니터즈는 경미 / 중대 / 즉시 영구로 나눠 **위반의 무게에 비례**하게 조치해요. 또 180일 기준으로 누적이 초기화돼 한 번의 실수가 영구히 남지 않아요.

### ⑥ 신고 수만으로 삭제하지 않음
- 토스증권은 신고 10회 누적 시 삭제돼, 비판 글을 신고로 지우는 "신고 몰이"와 과도한 정지(이른바 '10년 정지' 논란) 우려가 보도된 바 있어요.
- 니터즈는 **임시 가림 후 사람이 최종 판단**하고, 초기 규모(목표 가입자 1,000명)를 고려해 기준을 5회로 낮췄어요.
- 서비스 · 운영 **비판 글은 제재 대상이 아님**을 운영자 약속으로 명시했어요.

### ⑦ 제재 중에도 "내 기록"은 보호
- 니터즈는 커뮤니티이자 **개인 기록 앱**이에요. 이용 제한 중에도 프로젝트 기록 조회 · 백업은 유지해, 제재가 사용자의 뜨개 기록 손실로 이어지지 않게 했어요. 두 서비스에는 없는 조항이에요.

### ⑧ 함뜨(오프라인 모임) 규칙 — 당근과 유사, 범위는 더 좁게
- 당근처럼 오프라인 만남의 안전 가이드(공개 장소 권장)를 두었어요.
- 추가로 **참가비 · 환불 기준 명시, 24시간 전 취소 안내, 노쇼 반복 시 함뜨 기능만 제한**처럼 모임 운영에 특화된 규칙을 넣었어요.
- 참가자 얼굴 사진의 무동의 게시 금지도 함뜨 맥락에서 추가했어요.

### ⑨ 사용자 콘텐츠 외부 활용 시 사전 동의
- 토스증권은 종토방 글의 활용에 대한 보상 · 동의 문제가 보도된 바 있어요.
- 니터즈는 작품 사진이 곧 창작물이라, **공식 SNS 등 앱 외부 소개 시 작성자 사전 동의**를 받도록 했어요 (인스타그램 캐러셀 운영과 연결).

## 3. 두 서비스에서 가져온 것

| 출처 | 가져온 요소 | 니터즈 적용 |
|---|---|---|
| 토스증권 | 누적 위반 기반 단계적 제한 | 등급별 누적 제재표 (4-2) |
| 토스증권 | 이의제기 후 위반 아니면 해제 | 이의제기 절차 + 누적 제외 (5-4) |
| 토스증권 | 변형 · 우회 표현(초성, 은어)까지 제재 | 욕설 항목에 "변형 · 초성 · 은어 포함" 명시 |
| 토스증권 | 게시물은 작성자 의견, 회사 입장 아님 | 책임의 범위 (7) |
| 당근 | 신뢰 · 존중 · 윤리 3대 가치 | 존중 · 창작자 보호 · 정직한 공유 (0) |
| 당근 | "~할 수 없어요" 친근한 가이드 톤 | 전체 문서 "~해요" 톤 |
| 당근 | 권장 행동을 먼저, 금지는 그다음 | 1장 권장 → 2장 금지 구성 |
| 당근 | 오프라인 만남 안전 가이드 | 함뜨 이용 규칙 (3) |
| 당근 | 이웃을 속이는 행위(사기 · 다단계 · 포교) 금지 | 함뜨 가장 영업 · 종교 권유 즉시 영구 |

## 4. 확정 전 결정이 필요한 사항

1. **신고 임시 가림 기준(5회)** — 출시 초 사용자 수에 따라 3회 또는 비율 기준으로 조정 여부
2. **이의제기 답변 기한(3영업일)** — 운영 인력 규모에 맞는지 확인
3. **도안 PDF 첨부 기능의 공개 범위** — 현재 PRD상 피드 공유 시 도안 PDF 노출 여부가 정의돼 있지 않아요. 운영규칙은 "피드에 노출되지 않음"을 전제로 작성했으므로, 개발 스펙에도 반영이 필요해요.
4. **신고 사유 목록** — 신고 화면 UI(현재 미트볼 메뉴 '신고')에 사유 선택 단계를 추가할지
5. **시행일** 및 이용약관과의 연결
