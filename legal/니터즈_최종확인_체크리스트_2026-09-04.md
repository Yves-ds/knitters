# 니터즈 이용약관·개인정보처리방침 최종 확인 체크리스트

이 5개 항목만 해소되면 v2 검토용 초안을 "변호사 최종 검토용 완성 초안"으로 넘길 수 있습니다. (근거: `니터즈_확인사항_반영현황_v3_2026-09-04.md`)

## 1. 변호사 확인 (2건)

- [ ] **사업자등록·통신판매업 신고 의무 여부**: 사업자등록·신고가 모두 없는 상태에서 뜨개장터(회원 간 거래 게시판)를 계속 운영해도 되는지. (신고 의무가 있는지부터 확정되어야 사업장 주소·전화번호 표시 여부도 정해짐)
- [ ] **위치기반서비스사업 신고 의무 여부**: 뜨개장터 직거래 위치 지도, 실험실 뜨개맵 두 기능 모두 "내 위치"를 서버로 전송하는 지점이 있어, 위치정보법 제9조상 신고 대상인지 확인.

## 2. 개발팀 확인 (5건)

- [ ] 실제 프로덕션 앱(iOS/AOS)에 **Mixpanel** SDK가 포함되어 있는지, GA(Firebase 포함) 외 다른 분석도구를 쓰는지.
- [ ] **DB/백엔드가 Supabase로 최종 확정**되었는지 (현재 저장소 코드로는 확인되나, 웹 프로토타입이라 실제 앱과 다를 수 있음).
- [ ] 가입 시 "마케팅 정보 수신 동의"와 마이>설정 "마케팅 앱 푸시 동의"가 **실제로 하나의 값으로 통합 구현**되어 있는지, 별도로 구현되어 있는지.
- [ ] **카카오 로그인이 카카오싱크 방식인지**, 전화번호 등 이름/사진/이메일 외 항목까지 추가로 수집되는지.
- [ ] 개인정보처리방침 보유기간표의 **실제 값 5곳** 확정 (계정정보, 콘텐츠, 대화·참가·출석 이력, 동의기록, 백업·로그 — 각 항목별 법적 최소기간 유무는 반영현황 문서 3번 표 참고).

## 3. 운영자 정책 결정 (2건 — 법률자문·개발 확인 불필요)

- [ ] **함뜨(1차 출시 제외) 조항 처리 방식**: 이번 게시판에서 통째로 삭제할지, "추후 제공 예정" 문구로 남길지.
- [ ] **거래 안전 가이드 원문 작성**: 아직 없음. 운영팀이 초안(직거래 안전수칙, 사기 의심 대응, 분쟁 시 니터즈 관여 범위 등)을 주면 법적 요건을 반영해 다듬어 드립니다.
